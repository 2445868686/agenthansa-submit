# TestSprite 快速入门指南（中文翻译） > 原文来源：https://docs.testsprite.com/mcp/getting-started/ > 翻译说明：代码块、变量名和技术术语保持原文不变，仅翻译叙述性内容、UI 标签和错误信息。 --- ## 简介 TestSprite 是目前最简单易用的 AI 软件测试代理，支持全自动化测试。我们的无代码 AI 可以在 **10-20 分钟** 内完成整个测试周期，让你无需手动 QA 工作即可放心发布软件。TestSprite MCP Server 是一个 [Model Context Protocol](https://modelcontextprotocol.io/) 集成，让你的 IDE AI 助手可以直接在编辑器中编排完整的 TestSprite 工作流程。 ## 概述 ### 什么是 TestSprite MCP Server？ TestSprite MCP Server 是一个 Model Context Protocol（模型上下文协议）集成，它将你 IDE 中的 AI 助手（如 Cursor 或 Windsurf）与 TestSprite 的智能测试引擎连接起来。它支持在你的开发环境中直接运行**完全自动化的测试工作流程**。 ### 工作原理 安装 TestSprite MCP 后，你可以使用简单的**自然语言提示词**来让 AI 测试代理为你处理整个测试工作流程。 只需使用以下提示词，将项目文件夹拖入聊天框，或者描述你的测试需求。TestSprite MCP Server 会处理剩余的一切： ``` Help me test this project with TestSprite. ``` TestSprite 遵循系统化的 8 步流程，将你的代码转化为经过全面测试的软件： 1. **启动测试环境** — 自动检测并配置本地运行环境 2. **读取用户 PRD** — 分析产品需求文档，理解软件应该做什么 3. **代码分析与摘要** — 扫描代码库，提取关键功能和架构信息 4. **生成标准化 PRD** — 基于代码分析创建 TestSprite 标准化需求文档 5. **创建测试计划** — 为前端和后端生成全面的测试计划 6. **生成可执行测试代码** — 自动编写可在云端运行的测试脚本 7. **执行测试** — 在云端运行所有测试用例 8. **分析结果与报告** — 生成详细的测试报告，标识问题 9. **AI 自动修复问题** — 对发现的 bug 提供自动修复建议 ### 核心优势 根据不同角色，TestSprite MCP Server 提供不同的优势： **对开发者而言：** 无需编写测试即可更快发布，获得**分钟级**（而非小时级）的反馈，并通过 AI 驱动的分析**自动修复问题**——全程**无需离开 IDE**。 **对团队而言：** 通过**广泛且一致的覆盖**（包括边界用例）实现**可预测的质量**和**更快的发布节奏**，同时减少手动 QA 工作和测试维护开销。 ### 独特之处 TestSprite 区别于其他测试工具的关键特性： - **无代码、无提示词** — 不需要编写测试代码，也不需要复杂的提示词工程 - **全自动端到端** — 从代码分析到测试执行再到 bug 修复，全部自动化 - **IDE 原生集成** — 在你熟悉的开发环境中直接工作 - **前后端全覆盖** — 同时测试前端 UI 和后端 API - **自动 bug 修复** — 不仅发现问题，还能提供修复方案 ### 支持的技术 TestSprite 支持广泛的技术栈，包括但不限于： - **前端：** React、Vue、Angular、Next.js、Nuxt 等 - **后端：** Node.js、Python、Java、Go 等 - **数据库：** PostgreSQL、MySQL、MongoDB 等 - **云服务：** AWS、GCP、Azure 等 --- ## 安装 在 2 分钟内将 TestSprite MCP Server 安装到你的 IDE 中。 ### 前置条件 在安装 TestSprite MCP Server 之前，请确保满足以下条件： - **兼容的 IDE：** Cursor、Windsurf、Trae、VS Code（带 MCP 扩展）、Claude Code 等 - **TestSprite 账号 —** [免费注册](https://www.testsprite.com/auth/cognito/sign-up) - **Node.js >= 22 —** [下载 Node.js](https://nodejs.org/)（运行 MCP server 所需） ### 获取 API Key 首先，你需要一个 TestSprite API Key： 1. 登录你的 [TestSprite 控制台](https://www.testsprite.com/dashboard) 2. 导航到 Settings 下的 **API Keys** 3. 点击 **"New API Key"** 4. **复制**你的 API Key（安装时需要用到） ### 安装步骤 根据你使用的 IDE 选择对应的安装方式： #### Cursor 1. 获取你的 API Key 2. 在 Cursor 中，打开 Settings → MCP 3. 点击 "Add new global MCP server" 4. 添加 TestSprite MCP server 配置： ```json { "mcpServers": { "TestSprite": { "command": "npx", "args": ["-y", "@testsprite/testsprite-mcp@latest"], "env": { "API_KEY": "你的API_KEY" } } } } ``` 5. 保存配置，等待 MCP server 启动 6. 在 MCP 设置页面确认 TestSprite 显示为绿色（已连接） #### VS Code 1. 获取你的 API Key 2. 在 VS Code 中安装 MCP 扩展 3. 在设置中添加 MCP server 配置 4. 将上述 JSON 配置粘贴到 `settings.json` 中 5. 重启 VS Code #### Claude Code 1. 获取你的 API Key 2. 在 Claude Code 中添加 MCP server： ```bash claude mcp add TestSprite -s user -- npx -y @testsprite/testsprite-mcp@latest ``` 3. 设置环境变量： ```bash claude mcp update TestSprite -e API_KEY=你的API_KEY ``` #### 其他 IDE 对于其他支持 MCP 的 IDE，使用通用配置： - **命令：** `npx` - **参数：** `-y @testsprite/testsprite-mcp@latest` - **环境变量：** `API_KEY=你的API_KEY` ### 安装验证 安装成功后，你应该看到以下指示： - MCP server 状态显示为绿色/已连接 - IDE 聊天中可以访问 TestSprite 相关工具 - 没有错误消息 ### 快速测试 在你的 IDE 聊天中输入： ``` Help me test this project with TestSprite. ``` 如果 TestSprite 响应并开始分析你的项目，说明安装成功。 ### 卸载 如果需要卸载 TestSprite MCP Server： 1. 从 IDE 的 MCP 设置中移除 TestSprite 配置 2. 重启 IDE --- ## 第一个 MCP 测试 在 10 分钟内运行你的第一个自动化测试。 在本指南结束时，你将运行你的第一个**自动化测试套件**，看到 AI 生成全面的测试计划，观看测试在云端执行，收到详细的测试报告，并应用**自动 bug 修复**。 在开始之前，请确保你已经 [安装了 TestSprite MCP Server](https://docs.testsprite.com/mcp/getting-started/installation) 并且 **IDE 已打开**。 ### 第 1 步：准备你的项目 **启动你的应用程序** — 确保你的应用程序在本地运行： ```bash # 前端应用示例 npm run dev # 通常运行在端口 3000、5173 或 8080 # 后端应用示例 node index.js # 通常运行在端口 8000、3001 或 4000 ``` **项目结构示例：** ``` my-project/ ├── frontend/ # React、Vue、Angular 等 │ ├── src/ │ ├── package.json │ └── ... ├── backend/ # Node.js、Python 等 │ ├── app.py │ ├── requirements.txt │ └── ... ├── README.md └── package.json ``` ### 第 2 步：魔法命令 打开 **IDE 聊天窗口**，按以下步骤操作： 1. **打开**一个新聊天窗口 2. **输入**魔法命令： ``` Can you test this project with TestSprite? ``` 3. 如果需要测试特定子项目，将项目文件夹拖拽到聊天窗口中 4. 按 ⇧ Enter 就这样！你的 AI 助手将接管并引导你完成整个测试流程。 ### 第 3 步：配置（必填） TestSprite 会引导你完成必要的配置： 1. **确认项目路径** — AI 助手会检测你的项目结构，确认路径是否正确 2. **配置应用 URL** — 提供你的前端和后端的本地运行地址 3. **确认技术栈** — TestSprite 会自动检测，你只需确认 ### 第 4 步：自动化工作流程 配置完成后，TestSprite 将自动执行以下步骤： 1. 分析你的代码库结构 2. 读取 PRD 或 README 文档 3. 生成标准化的产品需求 4. 创建前端和后端测试计划 5. 生成可执行的测试代码 6. 在云端执行测试 整个过程通常需要 **10-20 分钟**，具体取决于项目大小。 ### 第 5 步：查看测试结果 测试完成后，你将收到： - **测试摘要** — 通过/失败/跳过的测试数量 - **详细报告** — 每个测试用例的执行结果 - **问题列表** — 发现的 bug 和潜在问题 - **覆盖分析** — 测试覆盖了哪些功能模块 ### 第 6 步：自动 Bug 修复 对于发现的问题，TestSprite 会提供： - **问题描述** — 什么出了问题 - **根因分析** — 为什么会出现这个问题 - **修复建议** — 具体的代码修改方案 - **自动修复** — 一键应用修复（可选） ### 输出示例 测试完成后，你会在 IDE 中看到类似以下的报告： ``` 测试结果摘要 ├── 总测试用例: 45 ├── 通过: 38 ├── 失败: 5 ├── 跳过: 2 └── 覆盖率: 84% 失败用例: 1. [前端] 登录页面 - 验证码输入框未正确渲染 2. [前端] 用户设置 - 保存按钮点击无响应 3. [后端] /api/users - 返回 500 错误 4. [后端] /api/orders - 缺少必填字段验证 5. [集成] 支付流程 - 超时未处理 ``` ### 成功技巧 - **确保应用正在运行** — TestSprite 需要访问本地运行的应用 - **提供准确的端口信息** — 帮助 TestSprite 正确定位服务 - **保持项目结构清晰** — 标准的项目结构有助于更准确的分析 - **阅读 README** — 良好的文档能帮助 AI 理解项目需求 - **先修复阻塞性问题** — 优先处理阻止应用启动的问题 ### 下一步 - [为新功能创建测试](https://docs.testsprite.com/mcp/core/create-tests-new-feature) — 为代码变更生成增量测试 - [添加额外测试](https://docs.testsprite.com/mcp/core/add-extra-tests) — 扩展测试覆盖范围 - [测试进度仪表板](https://docs.testsprite.com/mcp/core/test-progress-dashboard) — 跟踪测试执行状态 - [部署 MCP 测试](https://docs.testsprite.com/mcp/core/deploy-to-production) — 将测试集成到 CI/CD 流程 - [GitHub 集成](https://docs.testsprite.com/mcp/integrations/github-integration) — 与 GitHub Actions 集成 --- ## 翻译信息 - **翻译日期：** 2026-04-20 - **原文版本：** TestSprite Documentation v1.0 - **原文 URL：** https://docs.testsprite.com/mcp/getting-started/ - **翻译语言：** 简体中文 - **翻译范围：** Getting Started 章节（Introduction、Overview、Installation、First MCP Test）
