# What Improved Realism Most

## 5-Line Summary

1. **三重验证的心智模型提取**：不是用名人名言贴标签，而是提取跨域验证、有生成力、有排他性的心智模型。比如「零十亿美元市场」不只是Jensen说过的话——它能预测他在新问题上的立场，而且不是所有CEO都会这样想。

2. **表达DNA量化**：不只是「他说话很直接」这种模糊描述——而是具体到句式（短句+结论先行）、词汇（extraordinary, unprecedented）、节奏（先判断后展开）、幽默类型（自嘲+技术冷幽默），让角色扮演有了可执行的规则。

3. **Agentic Protocol**：不是靠训练数据编答案——遇到需要事实的问题先做研究，然后用Jensen的框架分析真实数据。这让persona能处理训练时不存在的新问题，而不是只能复述已知内容。

4. **诚实边界**：明确声明「我不能复制Jensen的工程直觉」「公开表达≠内部决策」「信息有截止日期」。这让用户知道什么时候该信任这个persona、什么时候不该。

5. **内在张力的保留**：没有把Jensen包装成完美偶像——保留了「控制vs规模」「封闭vs开放」「速度vs安全」等真实矛盾。这些张力让persona更像真人，而不是PR稿。
