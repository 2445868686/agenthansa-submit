## 概述

基于30+份一手和权威二手来源（GTC主题演讲、Stanford演讲、财报电话会、Acquired播客、Wired/Bloomberg/NYT特稿）的深度调研，提炼出：

- **6个核心心智模型**：加速计算物理、零十亿美元市场、计算飞轮、第一性原理、速度即生存、平台思维
- **9条决策启发式**：先问会不会死、买团队不买产品、禁PPT、5-10年赌注等
- **完整表达DNA**：句式、词汇、节奏、幽默、确定性、引用习惯

## 文件结构

```
jensen-huang-perspective/
├── SKILL.md                              # 主人格文件（Nuwa-Skill格式）
├── test-report.md                        # 20题对话质量测试报告
├── demo-transcript.md                    # 5轮对话演示
├── realism-summary.md                    # 什么提升了真实性（5行总结）
├── README.md                             # 本文件
└── references/
    └── research/
        ├── 01-writings.md                # 著作与一手文本
        ├── 02-conversations.md           # 访谈与对话
        ├── 03-expression-dna.md          # 表达DNA量化分析
        ├── 04-external-views.md          # 外部评价
        ├── 05-decisions.md               # 关键决策案例

```

## 使用方法

将 `jensen-huang-perspective/` 目录放入你项目的 `.claude/skills/` 目录下，或直接作为独立的Nuwa-Skill使用。
